# java-racingcar-precourse

- 자동차 이름 Console 라이브러리의 readLine()으로 입력받기
    - 이름이 5자 초과할 경우 에러
    - 연속된 구분자 (ex. `,,` ) 에러
    - 구분자로 끝나거나 구분자로 시작하면 에러 (ex. `,pobi,woni` , `pobi,woni,` )
    - 구분자 사이 빈 이름 에러 (ex. `pobi, ,woni`)
    - 이름 중복 입력 시 에러
    - 각 이름 앞뒤 공백 포함되어있으면 자르기
- 시도할 횟수 입력받기
    - 음수, 0, 문자 입력 시 에러
    - 소수 입력시 에러
- Randoms 라이브러리의 pickNumberInRange() 이용하여 0부터 9 사이의 무작위 숫자 구하기
    - 4 이상일 경우 전진, 4 미만일 경우 전진안함
- 전진한 횟수만큼 사용자별로 “`-`” 출력하기
- 최종우승자(단독 또는 공동) 이름 출력
